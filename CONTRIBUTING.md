# Contributing

Garage Level Lab is a small public research experiment.

## Useful contributions right now

Issues are welcome for:

- reproducible bugs;
- Android/device compatibility problems;
- incorrect OpenStreetMap interpretation;
- field-test observations that do not include sensitive location history;
- documentation corrections with a clear source.

## Code contributions

Unsolicited code pull requests are not currently accepted.

The project uses a noncommercial source-available license and may require separate commercial licensing. Keeping code authorship simple avoids creating unclear relicensing rights while the experiment is small. If outside code contributions are opened later, the repository will add an explicit contribution/licensing process first.

## Field reports

Useful reports include:

- phone model and Android version;
- whether a barometer is present;
- garage shape/type (open, enclosed, underground, split-level, spiral, etc.);
- actual physical floor transitions;
- what the app detected;
- any relevant pressure disturbance such as doors/windows/HVAC.

Do not publish exact routes, home/work locations, or other private information merely to report a test.
